# Exercise design for young ESL learners — research notes (2026-10-19)

Short notes behind the worksheet, dictation and unit-test changes. Greek-L1 classes, A–E Senior (about ages 8–13, Pre-A1 to B1).

## What the evidence says

| Finding | Source | What we changed |
|---|---|---|
| **Cambridge YLE** (Starters / Movers / Flyers) tests all four skills with short, picture-led tasks: *look and read, write yes/no about a picture, look and write the word, read and choose, listen and draw lines / tick the box / colour*, a short speaking interview with picture prompts. Every part opens with a worked **example**. Item counts are small (5–7 per part). | [Cambridge YLE handbook](https://assets.cambridgeenglish.org/network-services/yle-handbook-for-teachers.pdf), [2018 update](https://www.cambridgeenglish.org/images/419671-young-learners-2018-exam-update.pdf), [overview handout](https://www.cambridgeenglish.org/Images/425863-yle-2018-update-overview-handout-final-spreads.pdf), [Flyers candidate info](https://www.cambridgeenglish.org/es/Images/24783-flyers-information-for-candidates-en-.pdf) | The unit **test** uses YLE-style task types per skill, each section with an example line (item 0), 5–8 items, plain imperative rubrics ("Look and read. Write yes or no."). The picture exercise (D25) became YLE "look and write" with real illustrations. |
| **Retrieval beats recognition and re-reading**; spaced, low-stakes retrieval improves long-term retention of vocabulary, also with primary pupils (Goossens et al.). The best spacing schedule is still debated. | [Learning Scientists summary](https://www.learningscientists.org/blog/2017/7/20-1), [spaced repetition review (EFL/ESL)](https://riset.unisma.ac.id/index.php/JREALL/article/view/25562), [classroom spaced retrieval poster](https://www.wisconsin.edu/opid/download/wtfs_reports/wtfs_17-18/2017-18-WTFS-Jacobson-Poster.pdf) | Tests and dictations lean on **recall** (write the word, complete the sentence) over pure recognition; the test builder mixes recognition → recall within each skill. Answer keys are balanced so guessing doesn't pay. |
| **Involvement load** (need + search + evaluation): tasks where learners must decide whether a word fits a context (evaluation) and produce it themselves give better retention than gloss-reading. | [Laufer & Hulstijn 2001, summaries](https://www.cambridge.org/core/product/5C5984B326F37FBF3A3DDA3C0EB2996C), [involvement-load studies](https://dialnet.unirioja.es/descarga/articulo/4596425.pdf) | Gap-fills with a word bank of **the exact forms needed**, sentence completion in a new context (never the table's collocation), T/F statements that require understanding, and a guided writing task in the test. |
| **Pictures + explaining the link** deepen processing; matching on one visual cue alone is shallow (students confuse similar pictures). | [Colorín Colorado: picture-word strategy](https://www.colorincolorado.org/node/68553), [lexical scaffolding study](https://halshs.archives-ouvertes.fr/halshs-00801053v1/file/Lexical_Scaffolding.pdf) | Picture items use the app's own illustrations (no ambiguous emoji) plus a short clue that separates look-alike pictures. |
| **Dictation variants** keep dictation communicative: *running dictation* (pairs: runner memorises chunks from a wall text, writer writes), *dictogloss* (short text read twice at normal speed, pairs reconstruct meaning and form), *gapped* (students fill the missing words while listening), *picture dictation* (listen and draw / listen and write the word for a picture). A dictogloss text is short and connected. | [busyteacher: 8 ways to use dictation](https://busyteacher.org/25011-8-great-ways-to-use-dictation-with-esl-students.html), [running dictation (Victoria DET, after British Council)](https://www.education.vic.gov.au/Documents/school/teachers/teachingresources/diversity/eal/continuum/rundictation.pdf), [dictation re-imagined (NGL)](https://infocus.eltngl.com/2017/07/20/dictation-re-imagined/), [10 creative dictation activities](https://eslgames.com/esl-dictation-activities/) | The new **Dictation** maker has five styles (classic, gapped, running, dictogloss, picture), with length, count, difficulty and grammar controls, and level-based defaults. |
| **Scaffolded writing** for young learners: model text → sentence frames → word bank → short independent writing (YLE Flyers writes 20+ words from pictures). | YLE handbook (above) | The test's writing section offers a frame or picture prompt with a word count and a simple marking rubric (content / vocabulary / accuracy). |
| **L1 support** in rubrics lowers anxiety for beginners without replacing English. | General YL practice; Greek φροντιστήριο norm | Optional Greek help line under each task (on by default for A–C Senior), and Greek instructions on/off in the test builder. |

## Design rules we now follow
1. Short imperative rubrics in the YLE style; a worked example where the task type is new.
2. 5–8 items per task; mixed answer keys (never all True / all Yes / all A; correct choice position spread across a, b, c).
3. Only the unit's words are answers; forms are inflected to fit the sentence and word banks show the forms to write.
4. Pictures are the app's illustrations (`assets/pics`, same trusted lookup as the arcade), never emoji.
5. Each skill has recognition → recall progression; writing is scaffolded; listening uses new short texts (not the per-word recordings).
6. Level defaults: sentence length and item counts follow the class profile (A Senior ≈ 7 words per sentence … E Senior ≈ 16).

## Five more Test Maker exercises (2026-10-21)
Checked against the Cambridge Starters/Movers/Flyers handbook (2024) and the A2 Key for Schools format (2020 update). Added only task types those exams use and that the app can print well:
- **Listen for the main idea** (L-GIST, C–E): several short recordings, one gist question each (A2 Key Listening Part 4) — listening for the point, not a word.
- **Choose the right reply** (R-REPLY, A–E): functional dialogue completion (Movers/Flyers Reading & Writing, older A2 Key) — distractors are real short-answer and tense errors.
- **Signs and messages** (R-SIGNS, C–E): notices, labels and messages, meaning in other words (A2 Key Reading Part 1).
- **Read and choose the word** (R-MCCLOZE, B–E): multiple-choice cloze, three options of the same word class (Movers Part 4, A2 Key Part 4).
- **Look and tick or cross** (V-TICK, A–B): picture + word, yes/no (Starters Reading & Writing Part 1).
Left out on purpose: "listen and colour" and "find the differences" (need composed scenes the app cannot draw well); a categorising task (needs a table layout the paper does not have yet).

## Test Maker exercise library (2026-10-20)

The test's exercise picker became a library of 37 task types (6 skills). Each task carries what the children do, why (what it trains), its kind (**recognise → recall → create**), the classes it suits (A–E fit range) and a small paper preview. Rationale per addition:

| Addition | Why |
|---|---|
| **Kind badges + "This test" mix bar** (recognise / recall / create) | Retrieval and production build stronger memory than recognition alone (see retrieval and involvement-load rows above); a fair unit test moves from recognising to recalling to creating, so the teacher sees the balance at a glance. |
| **Class fit** ("Great for B Senior", "A stretch", "Easy") and per-class defaults | YLE task types change with the level (Starters picture-led → Flyers longer texts and own writing). Defaults follow that path: A/B start picture-led, C mixes, D writes an email, E an opinion paragraph. |
| **Reading:** who said it / questions / put the events in order / words in the text, plus 81 ready-made unit texts (fact, story, everyday text per unit of CPP 1–3) | Children need to *read connected text* that recycles the unit's words in a new context (involvement load: search + evaluation). Story texts suit sequencing; texts are 50–95 words in CPP1, 60–125 in CPP2, 85–160 in CPP3, in line with YLE reading lengths. |
| **Listening:** match people to things, complete the notes; plays once/twice; dialogue or monologue | YLE "listen and draw lines" and Flyers/KET note completion; hearing it twice is the YLE norm for young learners, once is a stretch for E Senior. |
| **Word families from A Senior** (class ladder: plural -s and -er/-y endings in A → un-/-ful/-ly in B–C → -ness/-tion/-able in D → two changes in E; the base word printed inside the answer boxes, s u n _ _, for young classes) | Morphological awareness grows with vocabulary from the first years and helps young learners decode and spell new words; starting with transparent, frequent endings keeps it within reach. |
| **Vocabulary:** unscramble/spell, word from its meaning, which words go together (collocation), word forms | Spelling and form-meaning recall; collocation and word-family work are the next step after single-word recall (B1 Preliminary word formation). Letter hints (first letters / letter count / none) scaffold by class. |
| **Grammar:** make the question, text cloze, translate from Greek | Question forming is a known gap for Greek learners; a cloze tests grammar in connected text; short L1→L2 translation targets L1 transfer errors explicitly. |
| **Writing:** sentences from starters, email/message, story from pictures, opinion paragraph; support full/some/none | Scaffolding fades with level: frames + word box → prompts only → independent writing (Flyers 20+ words, A2 Key email 25+, B1 Preliminary story/opinion ~100). |
| **Speaking:** tell the story, discuss a question | YLE picture-story and Key/Preliminary discussion tasks. |

Part settings (text length, text type, recording, plays, options, hints, support, difficulty) live on each part and reach the AI brief; the class's defaults fill what the teacher leaves untouched.

_Limits: most of the classroom evidence on spacing and involvement load comes from small studies or older learners; we use it as guidance, not proof._

## Word families, opposites, synonyms (2026-10-22)

| Addition | Why |
|---|---|
| **The words carry what the class learned with them** (word bank `derivatives`, `antonyms`, `synonyms`, `collocation`; CPP1 Unit 7 has the teacher's own, e.g. produce → production, useful ↔ useless, bug = insect). The Test Maker's prompt lists them, its family/opposite/synonym parts use them first, and the answer check and word check accept them. | Teaching derivatives together with their root is the advice from studies of how learners build word families (Schmitt & Zimmerman; Bauer & Nation's affix levels put the transparent, frequent endings first). A test should check the forms that were taught, not new ones the AI invents. |
| **Choose the right word form** (V-FAMMC: three forms of one family, the sentence decides) before **Word families** (V-FORM: write the form) | Receptive before productive: recognising a form is an easier, earlier stage than producing it, so a family part for A–B Senior starts with a choice; V-FORM stays for recall. |
| **Choose the opposite** (V-OPP) → **Write the opposite** (V-OPPW, letter help) | The same recognise → recall step for opposites. The word stands in a sentence because many words have more than one opposite (a LIGHT bag → heavy, a LIGHT room → dark; TeachingEnglish's note on antonyms of *rich* / *hard*). |
| **Same meaning** (V-SYN), with the opposite as a wrong option | Synonym, antonym and association items are the standard probes of *depth* of word knowledge (word associates format; Read). Putting the opposite among the options makes a topic guess fail: the child must know the meaning. |

Sources: Zhang & Koda (2017), *Assessing L2 vocabulary depth with word associates format tests*; Schoonen & Verhallen (2008), *The assessment of deep word knowledge in young first and second language learners*, Language Testing; Nation, *Word parts* resources (Victoria University of Wellington); British Council TeachingEnglish, *Antonym*. Formats vary a lot between studies and most evidence is from older learners — guidance, not proof.

## Eight more Test Maker exercises and a worksheet one (2026-10-23)
Checked against the Cambridge Young Learners formats (Starters / Movers / Flyers papers), B1 Preliminary for Schools (2020 format) and the vocabulary-assessment research on *depth* of word knowledge. Each one asks for something the 51 existing tasks don't: whole-text links, meaning in use, organising words, producing a word in your own sentence, and the Greek → English recall Greek schools use daily.

| Addition | Source format / evidence | Why it is not a duplicate |
|---|---|---|
| **Complete the conversation** (R-CONV, B–D): one person's lines printed, the other's replies in a lettered list with 1–3 extra replies | Flyers Reading & Writing Part 2 (choose A–H to complete a conversation) | R-REPLY is one exchange at a time with three options; here the replies come from one shared list, so the whole conversation must be followed. |
| **Put the missing sentences back** (R-SENT, D–E): whole sentences taken out of a text, lettered list with extra sentences | B1 Preliminary Reading Part 4 (5 gaps, 8 sentences, 3 extra) — tests text structure and cohesion | R-GAP / G-CLOZE remove single words; this removes sentences, so the links between sentences (pronouns, "But", "Then") decide. |
| **Read and tick the picture** (V-PICREAD, A–B): a short description, three of the app's pictures | Starters / Movers picture-choice tasks; L-PIC is the listening version | The reading route to the same recognise-with-pictures step; the first vocabulary task with picture options. |
| **Is the word used correctly?** (V-RIGHT, B–E): sentences with a word in CAPITALS, used correctly or not | Sentence-meaning judgement, a standard depth probe (Read 2000, *Assessing Vocabulary*; Schmitt 2014 on depth tests); worksheets already have L13 | Knowing what a word means *in use*, not its translation. The key is re-checked by a second reader (the same key check the yes/no reading parts use). |
| **Find the wrong word** (V-FIX, C–E): one real but wrong word in [brackets], write the unit word | Worksheets' D08 Sentence fixer; error-correction tasks | G-FIX fixes grammar; this is a meaning error between confusable words, then recall of the right one. The app checks the bracketed word is not the answer. |
| **Put the words in groups** (V-SORT, A–E): a word box and a table with 2–3 group headings | TeachingEnglish "categorisation" (learners sort language into groups the teacher gives); worksheets' D16. Sorting *learned* words is fine; teaching new words in semantic sets can interfere (Tinkham 1993, Waring 1997), so it is a review/test task only | Left out on 2026-10-21 for want of a table layout — the paper and Word now print a real table, the same number of lines in each column so it gives nothing away. |
| **Use the word in a sentence** (V-USE, B–E, 2 points each): the word in CAPITALS and an idea from the child's life | Involvement load: writing an original sentence has the highest load (Laufer & Hulstijn 2001; Hulstijn & Laufer 2001); the Vocabulary Knowledge Scale's top level is "I can use this word in a sentence" (Paribakht & Wesche 1997) | The only vocabulary task where children *produce* the word in a context they make; W-SENT finishes starters about themselves without target words. A model sentence and a 2-point marking guide go in the teacher's pack. |
| **Write the English word (from Greek)** (V-GREEK, A–E, letter help) | Meaning-recall from L1 is the most direct form–meaning test; bilingual versions of Nation's vocabulary tests are recommended for low levels | No task used the Greek. The Greek is taken from the word list (the AI writes none), so the meaning shown is exactly what the class learned. |
| **Worksheets: Own sentence** (D29, B–E) | Same evidence as V-USE | The worksheets had no productive sentence-writing type below E Senior (L10 is personal questions, E only). |

Left out on purpose: "listen and colour/draw" (composed scenes), word searches (little evidence they build knowledge), key-word sentence transformation (B2 level, beyond the classes), multiple-meaning "one word for three sentences" (C1 Advanced).

Sources: https://www.cambridgeenglish.org/exams-and-tests/qualifications/young-learners/paper/flyers/format/ · https://www.cambridgeenglish.org/images/563304-B1-Preliminary-for-Schools-Reading-Part-4.pdf · https://www.esl-lounge.com/student/exams/b1-preliminary-exam-reading-paper-guide-gapped-text.php · https://www.teachingenglish.org.uk/article/categorisation · Laufer & Hulstijn (2001), *Incidental vocabulary acquisition in a second language: the construct of task-induced involvement*, Applied Linguistics · Paribakht & Wesche (1997), the Vocabulary Knowledge Scale · Read (2000), *Assessing Vocabulary*, CUP · Tinkham (1993) / Waring (1997) on semantic clustering. As above: guidance, not proof — most studies use older learners.

## Worksheet exercises: one library with the Test Maker (2026-10-24)
The worksheet's 42 exercises (D01–D29 Dictation, L01–L13 Lingo practice) now live in `studio/worksheet-tasks.js` with the Test Maker's fields: kind (**recognise → recall → create**), class fit (A ≈ Starters/Movers, B Movers, C Flyers, D A2 Key, E B1 Preliminary), a blurb, what it trains and a paper preview. The class profiles' exercise lists (`allowDictation` / `allowLingo`, the smart mix's pool) are now *derived* from the fit ranges, so the list, the badges and the mix can't disagree. Any exercise can still be picked by hand ("A stretch" / "Easy", as in the Test Maker).

What the audit changed (old → new), and why:

| Exercise | Was | Now | Why |
|---|---|---|---|
| L08 Sentence order | D–E only | A–E | Word order with given words is a Starters/Movers task; the Test Maker's G-ORDER is A–E. |
| D17 Collocation pair | A–E | C–E | Collocations come after single-word meaning; the Test Maker's V-COLLOC is C–E. |
| D06 Synonym select | A–E (L03 B+) | B–E | Same-meaning words after opposites (V-SYN B–E); now consistent with L03. |
| D11 Odd one out | C–E | A–D | Picture/meaning groups are fine from Starters (V-ODD A–D); L09 was already A. |
| D12 Riddle | C–E | A–D | The Starters Reading Part 4 was a riddle until 2018. |
| D21 Sequencing | D–E | B–E | Ordering events/steps is in Movers/Flyers (R-ORDER A–D). |
| D22 Crossword clue | E only | B–E | A clue + letter count is a definition task with help (V-DEF B–E). |
| D28 / L12 Spelling check | B+ / C+ | both B–E | One rule for the same task. |
| D04 Phrase completion | A–E | B–E | Recall with no help at all; A Senior do better with a word box (Starters Part 4 gives one). |

Odd one out, riddles, register and minimal pairs are recognise. Own sentence and personal questions are create. |
| A/B Senior "definitions FORBIDDEN in dictation" | while D01 (definition + word bank) was their seed exercise | "very simple" / "simple" definitions | Movers Reading & Writing Part 1 *is* definitions → word; the rule contradicted the class's own exercise. |
| 13 exercises without a format rule for the AI (D07, D09, D10, D14, D18, D19, D21–D24, L06–L08, L10) | — | a rule each | So their lines come out in one printable, markable shape. L09 now groups by meaning for A–C and by word class only for D–E. |

The smart mix keeps at least one recognise and one recall exercise and adds a "create" one with the class's share (none for A Senior, more with age) — retrieval and production over recognition alone (see the evidence table above). Each exercise also has its own settings like a Test Maker part (lines, a 5-step difficulty, the word box for D01/L01/L05, the teacher's wish), sent to the AI as an EXERCISE SETTINGS block.
